# System call stubs of bionic-freebsd: the FreeBSD counterpart of
# SYSCALLS.TXT.  tools/parity/parse_syscalls_master.py checks each row
# against the pinned FreeBSD sys/kern/syscalls.master and writes the stubs.
#
# Each row has bionic's SYSCALLS.TXT format plus two columns:
#
#     func_name[|alias_list][:syscall_name](parameter_list) arch_list kind parity
#
# syscall_name is a FreeBSD system call.  The parameter list uses the
# FreeBSD argument order and count.
#
# kind:
#     E  same name and core behavior as the Linux system call
#     N  a FreeBSD system call with another name does the work
#     L  libc emulation on native primitives (no stub)
#     G  no FreeBSD equivalent yet (no stub)
#     F  FreeBSD-only system call that bionic-freebsd uses (parity "-")
#
# parity is the Linux system call of docs/specs/syscall-parity.md.
#
# v1: 65 rows, for a static program with bionic's startup and stdio, and for
# threads (M1).
